# Changelog

User-visible and operational changes, newest first. Dates are merge/commit dates.

## Unreleased

### Added
- Privacy policy page at `/privacy` (fr/en) with a footer link. It is a draft until `NEXT_PUBLIC_PRIVACY_REVIEWED=1`; contact comes from `NEXT_PUBLIC_PRIVACY_CONTACT`.
- New brand app icon (sage tile, italic K and sparkle): maskable and rounded Android icons, an opaque iOS touch icon and a favicon, generated by `scripts/build-icons.mjs`.
- Playwright end-to-end tests (`npm run test:e2e`) that run the app against an in-memory KV.
- Tests for the server pages and for races (reservations, edits, pledges, account purge).
- Deleting an account no longer destroys the pots it organised when others pledged: the pot passes to its biggest remaining pledger (see `docs/decisions.md`). Pots with no other pledger are still dropped.
- Install prompt: a dismissible banner (fr/en) offering to install the PWA, using `beforeinstallprompt` on Android/desktop and an "Add to Home Screen" hint on iOS Safari; hidden when already installed and for 30 days after dismissal.
- Route tests for the account routes (`user/me`, password, export, stats) and register; concurrency tests for pledges.
- CSV export of pledges for organisers of a wishlist pot and of a per-wish gift pot.
- Account deletion now removes everything tied to the user, not just their own wishlists: pledges, comments, reservations and purchases on other people's lists and invitations they received; pots they organised pass to the biggest remaining pledger.
- `scripts/kv-backup.mjs` (KV backup / restore) and `scripts/cleanup-orphans.mjs` (find and remove orphaned keys); see `docs/runbook.md`.
- Tests (Vitest, in-memory KV) covering funded-status reconciliation, pot role rules, CSV output, the account purge, and wish/wishlist routes (CRUD, access, comments, share, pledges).
- `docs/runbook.md`, `docs/decisions.md`, `.env.example`; a real README.

### Fixed
- **Two people could both reserve the same wish**, and an owner edit could overwrite a concurrent reservation, cancellation or purchase. Every writer of a wish or wishlist record now takes a per-record lock and re-reads inside it.
- Concurrent pledges on the same pot could lose each other (replace-pledge read-modify-write) and a pledge could overwrite a concurrent edit to the wishlist/wish record; pledge writes now run under a per-pot lock and re-read the record inside it. A pot that stays busy answers 503.
- **Access control:** anyone signed in could add a suggested wish to any wishlist, including private ones and ones with suggestions turned off; the server now requires visibility and honours `allowSuggestions`.
- Guests invited to a **private** wishlist can now reserve, mark purchased and pledge to pots (these routes previously only allowed public lists).
- `/api/wishlist/contribute` answered the wishlist owner differently depending on whether a surprise pot existed (409 vs 403); the owner is now refused first.
- Service worker: user data (pages, RSC, API) is no longer cacheable, and old caches are purged. (A service worker is not currently generated by the Turbopack build; see the roadmap.)

### Changed
- `npm run build` now uses `next build --webpack`, so the service worker is actually generated and registered in production (it was silently missing under Turbopack). Dev still uses Turbopack.
- Theme/background colours in the manifest and viewport follow the design tokens, light and dark.
- Lint is at 0 warnings; the React 19 rules (`purity`, `set-state-in-effect`, `exhaustive-deps`) are errors. The wishlist "date" sort no longer calls `Date.now()` during render, the anonymous fallback user id is stable, and the event bus is typed without `any`.
- Imports reordered across ~100 files (`eslint --fix`); `import/order` is now an error.
- Deleting a wish or wishlist, replacing a pledge, creating a wish/wishlist, inviting someone and signing up now run as single KV transactions, so a mid-way failure no longer leaves orphaned keys.
- Deleting a wish or wishlist now also deletes its comments (they were previously left behind).
- `src/middleware.ts` renamed to `src/proxy.ts` (Next 16 convention).
- ESLint works again on Next 16 (native flat config). `npm run lint` reports 0 errors; import-order and a few React 19 rules are warnings.

### Removed
- The dead mock layer: `lib/mock*.ts` files and every `useMock` flag.
